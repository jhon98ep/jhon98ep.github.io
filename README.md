# Portafolio · Jhon Jader Estrada

Sitio personal en [jhon98ep.github.io](https://jhon98ep.github.io): proyectos, trabajo para clientes, experiencia y contacto, en español e inglés.

## Stack

- Angular 22 (componentes standalone, signals, sin zone.js)
- SCSS sin librerías de UI
- Despliegue automático a GitHub Pages con GitHub Actions

## Desarrollo

```bash
npm install
npm start
```

El contenido (textos en ambos idiomas, proyectos y experiencia) vive en `src/app/content.ts`.
Las capturas de cada proyecto van en `public/projects/<id>/` y se referencian en el campo `images`.
